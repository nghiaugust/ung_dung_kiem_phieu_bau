CHI TIẾT HỆ THỐNG KIỂM PHIẾU

1. Mục tiêu
Hệ thống hỗ trợ kiểm phiếu tự động bằng web app Django kết hợp AI server. AI server hiện dùng hai model:
- VietNameOCR: OCR tên ứng viên.
- YOLO: nhận diện dấu X trên ô lựa chọn.

2. Luồng xử lý phiếu
- Upload phiếu bầu.
- Tiền xử lý và cắt các ô trong bảng phiếu.
- Với cấu hình 1, cột họ tên được gửi tới VietNameOCR.
- Cột đồng ý/không đồng ý được gửi tới YOLO.
- Hệ thống ghép kết quả OCR và YOLO để tạo BallotSelection.
- Kết quả được lưu để thống kê và hậu kiểm.

3. Thành phần chính
- `UDKPB/kiem_phieu_bau/`: Django web app.
- `UDKPB/kiem_phieu_bau/counting/`: cấu hình model, gọi AI API và lưu kết quả kiểm phiếu.
- `UDKPB/ai_core/ai_server/`: API server cho VietNameOCR và YOLO.
- `UDKPB/ai_core/model_vietnameocr/`: mã nguồn, config và weights VietNameOCR.
- `UDKPB/ai_core/model_yolo_x/`: weights YOLO.

4. API AI server
- `POST /api/vietnameocr/recognize/`: nhận nhiều ảnh ô tên, trả về text.
- `POST /api/yolo/detect/`: nhận nhiều ảnh ô lựa chọn, trả về label và detections.
- `GET /api/health/`: trạng thái model.
- `GET /api/info/`: thông tin model và thiết bị.

5. Cài đặt model
- Đặt `mobilenet_svtr_ctc.pth` tại `UDKPB/ai_core/model_vietnameocr/VietNameOCR/weights/`.
- Đặt `best.pt` tại `UDKPB/ai_core/model_yolo_x/`.

6. Vận hành
- Chạy AI server bằng `python run_waitress_ai.py` trong `UDKPB/ai_core/ai_server`.
- Chạy web app bằng `python manage.py runserver` trong `UDKPB/kiem_phieu_bau`.
