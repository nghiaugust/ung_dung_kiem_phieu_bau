II. HỆ THỐNG XỬ LÝ PHIẾU BẦU (ballot_processing_system)
================================================================================

A. QUY TRÌNH XỬ LÝ PHIẾU BẦU (TrOCR + YOLO)
────────────────────────────────────────────────────────────────

1. Tiền xử lý ảnh (core/tien_xu_ly.py):
   ┌─────────────────────────────────────────────────────────┐
   │ Bước 1: Phát hiện ArUco markers (4 góc phiếu)          │
   │ Bước 2: Làm phẳng phiếu (perspective transform)        │
   │ Bước 3: Cắt thành 10 dòng x 4 cột (STT, Tên, Đồng ý,  │
   │         Không đồng ý)                                   │
   │ Bước 4: Resize + padding với chất lượng cao            │
   └─────────────────────────────────────────────────────────┘
   
   Layout phiếu:
   - Hỗ trợ 2 layout: data1 và data2 (auto-detect)
   - data1: Y_MIN=208, Y_MAX=2225, COL_BOUNDARIES=[385,974,1233,1481]
   - data2: Y_MIN=204, Y_MAX=2128, COL_BOUNDARIES=[268,1009,1339,1648]
   - Ước lượng marker thiếu nếu chỉ detect được 3/4 markers

2. Nhận diện tên (core/trocr.py):
   ┌─────────────────────────────────────────────────────────┐
   │ • Load model TrOCR (microsoft/trocr-base-printed)      │
   │ • Cắt từng từ riêng biệt trong ảnh tên                 │
   │ • Tiền xử lý: khử nhiễu, CLAHE, threshold, morphology  │
   │ • OCR từng từ rồi ghép lại                             │
   │ • Hậu xử lý: sửa lỗi OCR thường gặp (0→O, 1→I, 5→S)   │
   └─────────────────────────────────────────────────────────┘

3. Phát hiện dấu X (YOLO):
   ┌─────────────────────────────────────────────────────────┐
   │ • Load model YOLO (models/best.pt)                     │
   │ • Detect 2 class: x_mark (X hợp lệ), x_cancelled (X    │
   │   bị gạch bỏ)                                          │
   │ • Chỉ tính x_mark là vote hợp lệ                       │
   │ • Lưu confidence, bbox cho từng detection              │
   └─────────────────────────────────────────────────────────┘

4. Tổng hợp kết quả (processors/trocr_yolo.py):
   ┌─────────────────────────────────────────────────────────┐
   │ PhieuBauProcessor.xu_ly_mot_dong():                    │
   │   - STT: Dùng số thứ tự dòng (1-10)                    │
   │   - Họ tên: TrOCR OCR                                  │
   │   - Đồng ý: YOLO detect x_mark                         │
   │   - Không đồng ý: YOLO detect x_mark                   │
   │                                                         │
   │ Kết quả JSON cho mỗi dòng:                             │
   │ {                                                       │
   │   "stt": 1,                                            │
   │   "ho_ten": "OLIVER JOHNSON",                          │
   │   "dong_y": true,                                      │
   │   "khong_dong_y": false,                               │
   │   "chi_tiet": {                                        │
   │     "ho_ten_ocr": "OLIVER JOHNSON",                    │
   │     "dong_y_yolo": {                                   │
   │       "co_dau_x": true,                                │
   │       "so_luong_x_mark": 1,                            │
   │       "so_luong_x_cancelled": 0,                       │
   │       "confidence_x_mark": [0.95]                      │
   │     },                                                  │
   │     "khong_dong_y_yolo": {...},                        │
   │     "loi": []                                          │
   │   }                                                     │
   │ }                                                       │
   └─────────────────────────────────────────────────────────┘

B. ĐÁNH GIÁ ĐỘ CHÍNH XÁC
────────────────────────────────────────────────────────────────

1. CER/WER (evaluation/cer_wer.py):
   - Character Error Rate: Tỷ lệ lỗi ký tự
   - Word Error Rate: Tỷ lệ lỗi từ
   - So sánh với ground truth (10 tên chuẩn)

2. Precision/Recall (evaluation/precision_recall.py):
   - So sánh kết quả detect dấu X với nhãn thật
   - Tính TP, FP, FN, TN
   - Tính Precision, Recall, F1-Score, Accuracy

3. Tỷ lệ phiếu (evaluation/ti_le_phieu.py):
   - Thống kê phiếu hợp lệ/không hợp lệ
   - Phân loại lỗi: chọn cả hai, không chọn gì, etc.

III. HỆ THỐNG WEB DJANGO (kiem_phieu_bau)
================================================================================

A. CƠ SỞ DỮ LIỆU (MySQL)
────────────────────────────────────────────────────────────────

1. Account (AbstractUser):
   - Kế thừa Django User (username, password, email)
   - role: admin, assistant, operator, user
   - is_active, created_at, updated_at

2. Poll (Cuộc bỏ phiếu):
   - poll_id (PK), access_code (mã tham gia 12 ký tự)
   - title, description
   - start_time, end_time (thời gian bỏ phiếu)
   - counting_start_time, counting_end_time (thời gian kiểm phiếu)
   - created_by (FK → Account), status
   - require_approval (yêu cầu phê duyệt thành viên)

3. PollMember (Thành viên cuộc bỏ phiếu):
   - member_id (PK), poll (FK), account (FK)
   - status: pending/approved/rejected
   - requested_role_change: assistant/operator (nâng cấp role)
   - assigned_by, approved_by, assigned_at, approved_at

4. Candidate (Ứng cử viên):
   - candidate_id (PK), poll (FK)
   - name, description, image_url

5. Voter (Cử tri):
   - voter_id (PK), full_name, email, external_id
   - has_voted (đã bỏ phiếu chưa)

6. Ballot (Phiếu bầu):
   - ballot_id (PK), poll (FK), voter (FK, nullable)
   - timestamp (thời gian bỏ phiếu)
   - is_checked (đã kiểm phiếu), is_valid (hợp lệ)
   - ballot_file_path (đường dẫn file ảnh)
   - metadata (JSON: thông tin mở rộng)

7. Ballot_Selection (Lựa chọn của phiếu):
   - selection_id (PK), ballot (FK), candidate (FK)

Quan hệ:
  Account 1─N Poll (created_by)
  Poll 1─N PollMember, Poll 1─N Candidate, Poll 1─N Ballot
  Candidate 1─N Ballot_Selection
  Ballot 1─N Ballot_Selection

B. CHỨC NĂNG CHÍNH (quan_ly_phieu_bau/views.py)
────────────────────────────────────────────────────────────────

1. Quản lý tài khoản:
   - register_view(): Đăng ký (role mặc định: user)
   - login_view(), logout_view(): Đăng nhập/xuất
   - account_list(), add_account(), edit_account(), delete_account()
   - account_profile(), edit_account_user()
   - Phân quyền: Admin quản lý tất cả, user tự chỉnh sửa

2. Quản lý cuộc bỏ phiếu:
   - tao_cuoc_bo_phieu(): Tạo Poll, tự động sinh access_code
   - danh_sach_cuoc_bo_phieu(): List polls (admin xem tất cả, user xem của mình)
   - poll_detail(): Chi tiết poll + danh sách candidates
   - edit_poll(), delete_poll()
   - join_poll(): User tham gia poll bằng access_code
   - poll_members(): Quản lý thành viên, phê duyệt

3. Quản lý ứng viên:
   - add_candidate(), edit_candidate(), delete_candidate()
   - Liên kết với poll_id

4. Upload & Kiểm phiếu:
   - upload_ballots_form(): Form upload ảnh phiếu (multiple files)
   - upload_ballots(): Lưu file vào media/{poll_id}/
   - kiem_phieu_sse(): Server-Sent Events stream xử lý phiếu
     • Gọi subprocess python processors/trocr_yolo.py
     • Stream log realtime về client
     • Lưu kết quả vào DB (Ballot_Selection)
   - list_ballots(): Danh sách phiếu đã upload

5. Hậu kiểm:
   - hau_kiem_view(): Hiển thị kết quả kiểm phiếu từng ballot
   - Cho phép sửa kết quả (chọn lại ứng viên)
   - Cập nhật Ballot_Selection

6. Thống kê:
   - thong_ke(): Tổng quan tất cả polls
   - thong_ke_detail(): Chi tiết 1 poll (số phiếu đồng ý mỗi candidate)

7. Tải mẫu phiếu:
   - download_sample_ballots_zip(): Tạo ZIP chứa ảnh mẫu phiếu

C. API CHO MOBILE APP (api/views.py)
────────────────────────────────────────────────────────────────

1. Authentication:
   - api_login(): POST username/password → trả token
   - api_logout(): DELETE token
   - Sử dụng APIToken model (token tự sinh, last_used tracking)

2. API endpoints:
   - api_polls_list(): GET danh sách polls
   - api_poll_detail(): GET chi tiết poll + candidates
   - api_poll_join(): POST tham gia poll bằng access_code
   - api_ballot_upload(): POST upload ảnh phiếu
   - api_ballot_process(): POST trigger xử lý phiếu
   - api_ballot_results(): GET kết quả kiểm phiếu
   - api_statistics(): GET thống kê poll

3. Authentication decorator:
   - @require_api_token: Kiểm tra header "Authorization: Token xxx"
   - Trả 401 nếu invalid/expired token

IV. QUY TRÌNH SỬ DỤNG HỆ THỐNG
================================================================================

A. DÀNH CHO NGƯỜI QUẢN LÝ
────────────────────────────────────────────────────────────────
1. Đăng nhập với tài khoản admin/assistant
2. Tạo cuộc bỏ phiếu mới:
   - Nhập tiêu đề, mô tả, thời gian
   - Hệ thống tự sinh access_code (xxx-xxx-xxx)
3. Thêm danh sách ứng cử viên
4. Chia sẻ access_code cho thành viên tham gia
5. Upload phiếu bầu (hình ảnh scan/chụp):
   - Chọn poll_id
   - Upload multiple files (.jpg, .png)
6. Kiểm phiếu tự động:
   - Click "Kiểm phiếu" → trigger AI processing
   - Theo dõi tiến độ realtime (SSE)
   - Kết quả lưu vào DB
7. Hậu kiểm:
   - Xem kết quả từng phiếu
   - Sửa nếu AI nhận dạng sai
   - Lưu lại
8. Xem thống kê:
   - Số phiếu đồng ý/không đồng ý mỗi ứng viên
   - Top candidate
   - Xuất báo cáo

B. DÀNH CHO THÀNH VIÊN
────────────────────────────────────────────────────────────────
1. Đăng ký tài khoản (role: user)
2. Nhập access_code để tham gia cuộc bỏ phiếu
3. Nếu require_approval=true: Chờ admin duyệt
4. Xem thông tin poll, danh sách ứng viên
5. Có thể xem thống kê (nếu được phân quyền)

C. DÀNH CHO MOBILE APP
────────────────────────────────────────────────────────────────
1. Login qua API → nhận token
2. Lấy danh sách polls
3. Join poll bằng access_code
4. Upload ảnh phiếu qua API
5. Xem kết quả thống kê

V. CÀI ĐẶT & TRIỂN KHAI
================================================================================

A. YÊU CẦU HỆ THỐNG
────────────────────────────────────────────────────────────────
- Python >= 3.8
- MySQL 5.7+
- (Khuyến nghị) GPU với CUDA cho TrOCR/YOLO

B. CÀI ĐẶT
────────────────────────────────────────────────────────────────
1. Clone repo, tạo virtual environment
2. pip install -r requirements.txt
   - django, torch, transformers, Pillow, opencv-python
   - numpy, ultralytics, mysqlclient, python-dotenv

3. Tải model TrOCR:
   python -c "from transformers import AutoModelForVision2Seq, AutoTokenizer, AutoProcessor; AutoModelForVision2Seq.from_pretrained('microsoft/trocr-base-printed', cache_dir='model_trocr'); ..."

4. Cấu hình .env trong UDKPB/kiem_phieu_bau/:
   SECRET_KEY=...
   DEBUG=False
   ALLOWED_HOSTS=localhost,127.0.0.1
   CSRF_TRUSTED_ORIGINS=http://localhost:8000
   DB_ENGINE=django.db.backends.mysql
   DB_NAME=udkpb
   DB_USER=root
   DB_PASSWORD=...
   DB_HOST=localhost
   DB_PORT=3306
   STATIC_URL=/static/
   MEDIA_URL=/media/

5. Tạo database MySQL:
   CREATE DATABASE udkpb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

6. Migrate database:
   cd UDKPB/kiem_phieu_bau
   python manage.py migrate

7. Collect static files:
   python manage.py collectstatic

8. Tạo admin:
   python manage.py shell -c "from quan_ly_phieu_bau.models import Account; Account.objects.create_user('admin', password='1', role='admin')"

9. Chạy server:
   python manage.py runserver 0.0.0.0:8000

C. PRODUCTION
────────────────────────────────────────────────────────────────
- Dùng gunicorn/waitress + nginx
- DEBUG=False, cấu hình ALLOWED_HOSTS
- Mở port 8000 hoặc reverse proxy
