1. Tổng quan công nghệ
Hệ thống gồm web application Django và AI server riêng. Web app quản lý nghiệp vụ bỏ phiếu, phiếu bầu, kiểm phiếu, hậu kiểm và thống kê. AI server cung cấp API nhận diện nội dung phiếu.

2. Backend
- Python, Django, Django ORM.
- Celery + Redis cho xử lý nền.
- MySQL cho dữ liệu nghiệp vụ.
- Django Channels/WebSocket cho cập nhật thời gian thực.

3. AI và xử lý ảnh
- VietNameOCR: nhận diện tên ứng viên từ ảnh ô họ tên.
- YOLO Ultralytics: nhận diện dấu X hợp lệ hoặc dấu X bị hủy.
- OpenCV + NumPy: tiền xử lý ảnh, cắt ô, tối ưu ảnh.
- QReader/qrcode: đọc và tạo QR code.
- PyTorch/TorchVision: nền tảng deep learning cho model OCR và YOLO.

Luồng xử lý chính: tiền xử lý phiếu -> cắt ô -> VietNameOCR đọc tên -> YOLO nhận diện lựa chọn -> tổng hợp kết quả theo từng dòng.

4. Triển khai
- Waitress cho môi trường Windows.
- Gunicorn/Nginx/Docker cho môi trường Linux/container.
- Redis và Celery worker xử lý upload/kiểm phiếu bất đồng bộ.

5. Bảo mật
- RSA/HMAC cho xác thực phiếu qua QR.
- AES-256-GCM cho dữ liệu nhạy cảm.
- Blind index SHA-256 hỗ trợ tìm kiếm an toàn.
- Rate limiting ở middleware.
